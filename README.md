# Paul Bricks & Blocks

Simple, mobile-first business management software for Paul Bricks & Blocks.

## Foundation
The project is being built as an installable PWA for Android-friendly use. The application will support multiple users with role-based permissions, audit history, sales/invoices, purchases, expenses, stock, labour, bills, and documents.

See docs/ARCHITECTURE.md for the current architecture and docs/PROJECT-STATUS.md for the current delivery status.

## Run locally

After cloning the repository:

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Foundation work is currently being developed on feature/foundation-v0.1 and will be reviewed before merging into main.
